## Projects

### Ecommerce Flow App — Microservice E-Commerce Backend
> A production-oriented backend system designed around service boundaries, transactional consistency, and asynchronous workflows

- Java 21 & Spring Boot
- Microservice architecture with independent service-owned databases
- API Gateway for routing and edge-level authentication
- Dedicated Auth, Customer, Product, Order, Inventory, and Payment services
- Synchronous service-to-service communication for real-time validation and queries
- Kafka-based asynchronous workflows for cross-service events
- Transactional Outbox pattern for reliable event publishing
- Saga-based coordination for distributed business workflows
- Idempotent event handling and retry-safe consumers
- Dead Letter Queue handling for failed asynchronous processing
- PostgreSQL & Flyway for versioned database migrations
- Spring Data JPA / Hibernate with explicit transaction boundaries
- Redis for authentication/session-related state and caching where appropriate
- JWT-based authentication and authorization
- Order lifecycle and aggregate-oriented domain design
- Product price/name snapshots for historical order consistency
- Pagination, deterministic sorting, and controlled JPA fetch strategies
- Unit, MVC, and persistence integration testing
- GitHub Actions CI for automated build and test validation
- Dockerized local infrastructure and deployment-oriented service configuration

🔗 https://github.com/erkutoguz/ecommerce
